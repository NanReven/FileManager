# Файловый менеджер

Приложение на Windows Forms для навигации по файловой системе.

## Основной функционал

- Переход в директорию (двойной клик на папку)
- Переход в родительскую директорию через "..."
- Отображение имени, даты изменения, типа и размера файлов
- Расчет размера каталога
- Экспорт данных таблицы в формате XML/JSON
- Импорт данных в таблицу из XML/JSON

## Дополнительный функционал
- При вводе несуществующей директории таблица не обновляется
- Каталоги выделяются голубым цветом
- При попытке перехода в скрытую директорию выводится предупреждение

## Структура проекта

- `MainForm.cs` - главная форма и обработчики событий
- `FileService.cs` - работа с файловой системой
- `DataSerialization.cs` - сериализация и десериализация в XML/JSON
